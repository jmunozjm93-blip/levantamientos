1 · Conexión con GitHub

Repositorio:
¿Cómo creo el token?
  1. Entra a github.com/settings/personal-access-tokens/new
  2. Token name: cargar levantamientos · Expiration: 1 año (o "No expiration")
  3. Repository access: "Only select repositories" → elige levantamientos
  4. Permissions → Repository permissions → Contents: Read and write (nada más)
  5. Generate token → cópialo y pégalo arriba. Queda guardado solo en este navegador.

Si ya tienes el token de pagina-web, puedes editarlo en GitHub y agregarle este repositorio en "Repository access".
